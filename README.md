# 📝 To-Do List Manager

A simple command-line **To-Do List Manager** built with Python. It allows users to add, remove, and view tasks while saving them in a text file for future use.

## 📌 About the Project

This project was created to practise fundamental Python programming concepts, including lists, functions, loops, conditional statements, and file handling.

## ✨ Features

- ➕ **Add Tasks:** Add new tasks to your to-do list.
- ❌ **Remove Tasks:** Remove tasks using their assigned numbers.
- 📋 **View Tasks:** Display all saved tasks.
- 💾 **Save Tasks:** Store tasks in a text file (`tasks.txt`).
- 📂 **Load Tasks:** Automatically retrieve previously saved tasks when the program starts.

## 🛠️ Technologies Used

- 🐍 Python 3
- 📄 File Handling (`open()`)
- 📋 Lists
- ⚙️ Functions
- 🔄 Loops and Conditional Statements

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/MarkBen244/To-Do_Manager.git
   ```

2. Navigate into the project directory:

   ```bash
   cd To-Do_Manager
   ```

3. Run the program:

   ```bash
   python main.py
   ```
